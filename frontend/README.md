# Training Readiness Prototype

A single-screen Next.js prototype demonstrating multi-day fatigue indicators,
morning energy and soreness check-ins, a three-day trend insight, and workout
adjustment choices. All values are illustrative mock data; check-in and option
changes remain in browser memory and reset on reload.

## Run locally

```powershell
npm install
npm run dev
```

Open the local address printed by Next.js.

## Validate

```powershell
npm run lint
npm run build
```

See [the feature quickstart](../specs/001-training-readiness/quickstart.md) for
the demonstration scenarios.
